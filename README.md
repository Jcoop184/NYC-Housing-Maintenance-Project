# NYC-Housing-Maintenance-Project

For this project, I built an end-to-end data pipeline using Housing Maintenance Violations data from NYC Open Data and the US Census Bureau API to analyze housing violation distribution and severity across New York City. The goal of the final dashboards was to communicate critical insights to the New York City Housing Preservation and Development department that would:
- Determine which boroughs suffer the greatest in terms of violation count and severity.
- Allow them to target housing developments for maintenance equitably
- Allow them to develop housing policy to mitigate landlord power and improve tenant agency

## Stack

1. Data Ingestion: Alteryx
2. Data Modeling: Snowflake
3. Data Visualization: Tableau
